# b2b-client-interest-model
Web application for analyzing customer interest in B2B sales based on mathematical models. The project implements linear and nonlinear models, optimal control, seasonal and impulse effects, numerical simulation, and visualization of results.


# B2B Client Interest Model

Web application developed as part of the bachelor's thesis "Mathematical Modeling of Potential Customer Attraction in B2B Sales".

The application allows:
- simulation of linear and nonlinear models;
- analysis of optimal control strategies;
- investigation of seasonal and impulse effects;
- numerical solution of differential equations;
- visualization of simulation results.
